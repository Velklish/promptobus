# Backfill ADR: как записать решения, которые уже приняты

Читается в фазах 2–3 скилла `backslop-seed`. Первый ADR — про сам процесс — уже лежит после `backslop init`; здесь про остальные.

## Сколько и какие

- **3–5 решений**, не вся история. Критерий: решение до сих пор ограничивает правки — сменить его дорого, и следующий читатель спросит «почему так». Фреймворк, хранилище, брокер, формат API, слоистость — обычные кандидаты. Мелкие выборы и умолчания инструментов — нет.
- Список кандидатов с уликами показывается владельцу **до записи**, инструментом опроса с множественным выбором. Владелец — авторитет в том, было ли решение решением или стечением обстоятельств.
- Решение, чья мотивировка не восстанавливается, записывается только по слову владельца — и тогда честно: «причина утрачена; записано по состоянию кода на <дата>».

## Форма записи задним числом

- `backslop adr <slug> --title "…"`, затем в файле:
  - **Status:** Accepted; **Date:** дата исходного решения по истории git (коммит, где выбор появился), не сегодняшняя;
  - **Deciders:** кто решал по словам владельца; неизвестно — «не установлено»;
  - в **Context** первой фразой: «Записано задним числом <сегодня>; решение действует с <дата>.»;
  - **Варианты** — только те альтернативы, о которых известно, что их рассматривали; неизвестно — «альтернативы не восстановлены»;
  - **Decision** — что выбрано, с уликой: манифест, конфиг, каталог;
  - **Consequences** — что решение до сих пор ограничивает: это самая полезная часть записи задним числом.
- Строка в таблицу `docs/README.md` тем же ходом — без неё `backslop lint` красный.

## Чего не делать

- Не переписывать историю: ADR не правится ради «как надо было». Решение изменилось — новый ADR со ссылкой на старый и пометка «заменён» в старом.
- Не выдумывать декорации: Decision Drivers и Pros/Cons, которых никто не взвешивал, вредят больше пустого раздела.
- Не заводить ADR на будущее решение из этого скилла — открытый вопрос идёт файлом в `triage/`, а ADR появится, когда решение примут.

## ADR в другом формате

Нашлись ADR в другом каталоге или шаблоне — вопрос владельцу: перенести в `docs/adr/` с сохранением номеров и дат (тогда нумерация backslop продолжает их) или оставить на месте и сослаться из индекса. Два параллельных журнала решений — худший вариант из трёх.
