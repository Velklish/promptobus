# Promptobus

[English](README.md)

Promptobus — локальный почтовый ящик и шина задач для сессий агентов. Воркеры и оркестратор обмениваются типизированными сообщениями, артефактами и статусом через общую задачу на диске, без одной общей чат-ленты.

Этот репозиторий — **скелет**. Манифест пакета, лицензия, раскладка трекера и каркас CI уже лежат. Реализация приедет следующими задачами; ставить пока нечего.

Канон — английский текст. Полноценную документацию пишет отдельная задача; здесь её наперёд нет.
