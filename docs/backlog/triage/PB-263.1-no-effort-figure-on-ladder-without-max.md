# PB-263.1 · A no-effort figure has no landing rung on a ladder without `max`

- **Scope:** [guides/model-routing](../../guides/model-routing.md), [adr-004](../../adr/adr-004-subscription-balance.md)
- **Created:** 2026-09-26
- **Dependencies:** none
- **Cost:** major

## Context

Finding discovered while reviewing PB-263.

Evidence: `docs/guides/model-routing.md:158` (§ Re-rating a row, step 1) says "a figure whose page names no effort lands on the base rung `max`, as every GPT-5.6 and GPT-6 Codex base row does". `docs/adr/adr-004-subscription-balance.md:257` instead says "where the source does not say, it is the harness's default effort". The two are the same rule only for a ladder whose base rung is `max`. GPT-5.5's Codex ladder (`models/catalog.json`: `codex-gpt55-low`, `-medium`, `-high`, `-xhigh`) has no `max` rung at all — `codex-gpt55-medium` is its base row. The Terminal-Bench 2.1 Codex CLI figure for GPT-5.5, 83.1 % ±1.1 (the archived leaderboard, https://snorkel.ai/leaderboard/terminal-bench-2-1/, opened 2026-09-23), names no effort. Landing it on `codex-gpt55-medium` under the guide's wording would assert that `medium` is the harness's default effort for GPT-5.5 under Codex CLI, which nobody has verified. Pending this, `codex-gpt55-medium`'s `quality` stays a hypothesis rather than citing the figure (PB-263).

## Work to do

- Decide the rule for a figure that names no effort when the model's ladder has no `max` rung: either establish (and record, with its own evidence) Codex CLI's default effort for the affected models, or state a fallback rung the guide and ADR-004 agree on for a ladder shaped this way.
- Update `docs/guides/model-routing.md`'s Re-rating a row step 1 and/or `docs/adr/adr-004-subscription-balance.md` so the two no longer read as two different rules for this case.
- Re-examine every base row without a `max` rung for the same gap, not only `codex-gpt55-medium`.

## Out of scope

- Any rating, band or citation change on `codex-gpt55-medium` or any other row — this entry is the rule question the citation was deferred on, not the citation itself.

## Verification

- The guide and ADR-004 agree on one rule for a ladder without `max`, and it names a concrete effort (or an explicit "no citation without it") for every base row currently missing one.
- `codex-gpt55-medium`'s `quality` is re-examined against the settled rule once this closes.
