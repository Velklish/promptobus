# PB-9.1 · promptobus-host.test.mjs asserts a dead Russian-localized bus-hook header

- **Scope:** [README](../../reference/README.md)
- **Created:** 2026-09-05
- **Dependencies:** none

## Context

Found while translating `test/promptobus-host.test.mjs` for PB-9. Two `check()` conditions accept
either the real English bus-hook header or a hypothetical Russian one:

```js
check('bus hook substitutes host commandName, not a hardcoded name',
  hookA.includes('Generated by alpha sync') && hookB.includes('Generated by beta sync')
  || hookA.includes('Сгенерирован alpha sync') && hookB.includes('Сгенерирован beta sync'),
  hookA.split('\n')[1]);

const planned = planPromptobusHooks(hostA);
check('hook plan writes the standalone bus-hook path',
  planned.rel === path.join('.promptobus', 'hooks', 'bus.mjs')
  && (planned.text.includes('Generated by alpha sync') || planned.text.includes('Сгенерирован alpha sync')),
  planned.rel);
```

Evidence that the Russian branch is unreachable, run in this tree:

```text
$ grep -n "Generated by\|Сгенерирован" templates/bus-hook.mjs src/hooks.ts
templates/bus-hook.mjs:1:// Generated by __COMMAND__ sync — hand edits are safe; a future sync only replaces this file.
```

`renderBusHook` (`src/hooks.ts`) substitutes `__COMMAND__` into this one English template; there is
no localization branch anywhere in `src/` or `lib/` that would ever produce the Russian header. The
Cyrillic half of each `||` is not a fixture standing in for a person's words or for real mechanism
output — it is dead test logic that has never been exercisable, most likely a leftover from before
the project standardized on English output.

Translating it in place (PB-9's usual move) would keep asserting on a string the code can never
produce; deleting the dead branch instead changes what the check accepts, which PB-9 draws out of a
worker's scope ("a check whose translation would change its meaning is a finding, not a rewrite").

## Work to do

  localization regression, in which case it should say so with a comment instead of reading as a
  fixture.

## Out of scope

- Any other Cyrillic in `test/**` — that is PB-9 proper.

  these two conditions); after this task it should report 0, or the remaining Cyrillic is next to a
  comment explaining why it stays.
