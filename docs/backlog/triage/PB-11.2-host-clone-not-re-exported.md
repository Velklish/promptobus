# PB-11.2 · HostClone is declared but not re-exported from either entry point

- **Scope:** [02-host](../../reference/02-host.md)
- **Created:** 2026-09-05
- **Dependencies:** none

## Context

Found in review of PB-11, which added `HostRoutingPaths` and `HostRoutingOverlay` and had to add them to both entry lists. `HostClone` is older and was never added.

Evidence, in this tree:

- `src/host.ts:100` declares `export interface HostClone`, and `PromptobusHost.cloneOf(abs): HostClone | null` at `src/host.ts:195` returns it.
- `src/host-index.ts:5–8` — the `export type { … } from './host.js'` list has `HostFreshness`, `HostLegacyLayout`, `HostModuleNote`, `HostRepo`, `HostRepoCandidate`, `HostRepoModule`, `HostRoutingOverlay`, `HostRoutingPaths`, `HostServers`, `HostToolBin`, `PromptobusHost`. No `HostClone`.
- `src/index.ts:97–98` — the same list, the same omission.

A consumer implementing `PromptobusHost` has to write `cloneOf`, and it cannot name that method's return type without copying the interface. `tsc` does not notice: the interface compiles, the package builds, and only the consumer's own build fails. This is the same shape of drift the `bin` field of `HostToolBin` carries a comment about (`src/host.ts:69`) — declared in one place, unreachable from the place a consumer reads.

## Work to do

- Add `HostClone` to the `export type` list of `src/host-index.ts` and of `src/index.ts`.
- Widen the entry-point check in `test/host.test.mjs` (`the routing types leave the package through both entry points`) from its current two names to **every** `export interface Host*` / `export type Host*` in `src/host.ts`, read from the source rather than listed by hand. Today that check names two types on purpose: `HostClone` would make a generic version red, and PB-11 was not the pass to fix it in. With `HostClone` exported, the generic version is the one that keeps the next type from being forgotten.

## Out of scope

- Any change to `cloneOf` or to what a clone is. This is an export list and a check.

## Verification

- `HostClone` appears in `dist/host-index.d.ts` and `dist/index.d.ts`.
- Mutation probe: drop one name from either entry list, the widened check goes red.
