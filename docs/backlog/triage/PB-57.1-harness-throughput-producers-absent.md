## Context

Finding of PB-57 (worker's measurement, run `pb-run-0909b-t20260909-184312`). PB-57 made `speed` calibration read a throughput observation — output tokens with model-active generation duration, or a harness-provided tokens/s — and forbade inventing one. What the harnesses give today: Cursor's Stop payload (`test/harness-cursor.mjs:1043-1055`) carries `generation_id`, `loop_count` and `output_tokens`, no duration and no rate, so its sidecar observation is partial and yields no rate; Codex's `turn/completed` (`test/harness-codex.mjs:620-626`) exposes only id/status/error and the session paths carry no usage fields; the Claude session and driver paths expose no participant token fields either. Consequence: every record's `throughput` is `null` or partial, and `models calibrate` proposes no `speed` for any model — the decision holds, the evidence does not exist yet.
