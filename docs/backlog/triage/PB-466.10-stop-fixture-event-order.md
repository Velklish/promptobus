# PB-466.10 · Make Stop fixtures observe deadlines and process exit deterministically

- **Scope:** [Drivers](../../reference/05-drivers.md)
- **Created:** 2026-11-20
- **Dependencies:** none
- **Cost:** major

## Context

[Quality audit of 2026-11-20](../triage/PB-466-quality-audit-20261120.md), source `54f22155430bdd6db65b4366ae1337b1e0dff00d`.

### PQA-3000 - Test the shared Stop deadline independently of scheduler delays

Audit priority: medium. Evidence status: confirmed.

Evidence: test/harness-stop-all.test.mjs:30-40 expects two stuck children to consume 950 to 1799 ms with a 1000 ms Stop budget. test/harness.mjs:585-594 gives the second child only the time remaining. A late wakeup can exceed the test limit even when both IDs and the remaining allowance are correct. Teardown also starts after both children are ready. The audit found a scheduling dependency without an observed failure.

Acceptance: Use controlled time to check both a partial and a zero remaining allowance. Giving each PID a fresh timeout must fail the budget assertion. Keep a real-process check for both IDs and their records, and verify that the first child's close is observed if the second startup fails. Run `npm run test:one -- harness-stop-all.test.mjs`.

### PQA-3004 - Observe holder exit before requesting shutdown in socket tests

Audit priority: medium. Evidence status: confirmed.

Evidence: test/codex-holder-admission.test.mjs:82-104 installs its exit listener after awaiting the shutdown reply in the cleanup and replacement cases. lib/codex-session.ts:1767-1771 schedules holder exit independently of reply delivery. If the child exits before the test handles the reply, the listener misses the event and the socket assertions can remain pending. The audit did not measure the frequency.

Acceptance: Register the exit or close promise at spawn and share it with teardown. Delay handling the shutdown reply until after the child exits. Both cases must finish and verify that the owned socket is removed and the replacement path survives. Run `npm run test:one -- codex-holder-admission.test.mjs`.
