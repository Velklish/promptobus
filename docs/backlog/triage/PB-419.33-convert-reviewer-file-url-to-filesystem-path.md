## Context

Evidence: `test/reviewer-files.test.mjs:131` passes a file URL's `pathname` to `spawnSync` as a filesystem path. URL pathname retains percent escapes; an isolated synthetic URL probe showed it differs from `fileURLToPath` for a path with a space (`equal:false`, exit 0). The actual test in a checkout with spaces or Unicode was not run.

## Work to do

Use `fileURLToPath` for the entrypoint and retain the stdio assertions.

## Acceptance criteria

The stdio test succeeds from a normal checkout and a checkout path containing spaces and Unicode, while still validating its output and exit status.

## Verification

After implementation run `npm run build` and `node --test test/reviewer-files.test.mjs` from both checkout paths; **notRun**.

## Dependencies and limits

None. The synthetic URL probe does not establish a failure in a real checkout.
