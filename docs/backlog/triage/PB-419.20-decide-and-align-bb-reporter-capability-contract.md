# PB-419.20 · Decide and align BB reporter capability contract

## Context

Evidence: `integrations/bb/skills/promptobus-reporter/SKILL.md` requires digest, status and ask operations. `integrations/bb/protocol.ts:116-118` and `runtime.ts` register mailbox, task and artifact tools for a reporter, deny send and do not guarantee those three operations. Generic optional Host tools do not establish equivalent authenticated root-tree operations. The role is offered by the integration; a historical live run does not establish the missing operations at this revision.

## Work to do

First decide the supported reporter contract: either provide and authorize equivalent bounded digest, status and ask/answer operations with the appropriate root-tree identity, or change reporter duties and support to an actually available route. Implement the chosen contract consistently in the generated instructions, runtime and tests. Preserve the ban on arbitrary reporter sends and writes.

## Acceptance criteria

- Tests exercise the actual reporter tool set and its supported journal/status and question flow with the intended scope.
- Foreign-task access and arbitrary reporter sends remain denied; generated instructions match the registered capabilities.

## Verification

After implementation run `npm run build` and `npm --prefix integrations/bb test` from the repository root; **notRun**.

## Dependencies and limits

Depends on an explicit reporter-contract decision. Live integration and external Host extensions were not tested; do not assume an optional consumer tool is universally present.
