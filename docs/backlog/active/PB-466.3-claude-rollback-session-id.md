### PQA-2011 - Confirm Claude admission rollback against the stopped session ID

Audit priority: medium. Evidence status: confirmed.

Evidence: lib/driver-claude.ts:828-831 selects a session by ref and actualId and stops that ID, then calls awaitSessionGone(ref). Lines 846-855 wait for every record with the same name to disappear. An older namesake can exhaust the ten-second timeout and prevent liveSeat.stopped() even after the target disappears. lib/liftoff.ts:280-294 accounts for old and current records sharing a name. The finding follows from the lookup predicates.

Acceptance: Use controlled registry responses containing two same-name records. Rollback confirms when the stopped ID disappears and the older ID remains. With the stopped ID still present, or with an unreadable registry, rollback leaves the stop unconfirmed. Preserve ordinary Stop behavior. Run node test/managed-claude-genesis.test.mjs.
