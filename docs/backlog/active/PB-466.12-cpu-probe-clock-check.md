### PQA-3002 - Distinguish CPU time from elapsed time in the load probe test

Audit priority: medium. Evidence status: confirmed.

Evidence: test/sandbox.mjs:192-207 waits for a CPU usage target with an independent elapsed-time limit. test/sandbox-load-scale.test.mjs:20-28 checks a minimum elapsed time for one case and the wall limit for another. Both allow an implementation that uses elapsed time for the CPU target. The current implementation reads CPU usage.

Acceptance: Exercise the probe with independently controlled CPU and wall clocks. Assert which target stops the probe when CPU reaches its target first and when wall time reaches its limit first. Replacing the CPU condition with elapsed time and removing the wall limit must each fail a specific check. Keep the real-child smoke and aggregation checks. Run `npm run test:one -- sandbox-load-scale.test.mjs`.
