## Context

Finding discovered while working on PB-178.1. That card can show a Cursor or Codex MCP child has no session identity. With no session, `gated` is false, so the mailbox tool fetches the inbox instead of peeking it. What was read moves to history: the originals are taken. Confirming the missing identity would leave nobody to remove that.
