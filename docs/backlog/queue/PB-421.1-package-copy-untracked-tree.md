# PB-421.1 · promptobus-package.test.mjs copies every untracked and ignored file of the checkout, and a clone with agent worktrees under .claude makes it the longest file of the pool

- **Order:** 70
- **Scope:** [Suite isolation](../../guides/contributing.md#suite-isolation)
- **Created:** 2026-11-05
- **Dependencies:** none
- **Cost:** major

## Context

`promptobus-package.test.mjs` builds its package fixture from a copy of the whole checkout and leaves out only three names:

<!-- quote:../../../test/promptobus-package.test.mjs -->
    if (base === 'node_modules' || base === '.git' || base === 'dist') return false;
<!-- /quote -->

Everything else is copied, including ignored and untracked trees. A clone whose agent sessions keep worktrees under `.claude/worktrees` pays for every one of them on every run, and the file becomes the longest of the pool; under a wide pool it reaches the runner's 300 s file timeout.

Evidence: 2026-11-05, eight cores, official Node 26.13.0. In the clone at `3f6483ab` `.claude/worktrees` holds 483 worktrees, 5.8 GB, 147 225 files (`du -sh`, `find -type f | wc -l`). `node test/promptobus-package.test.mjs` there: exit 0, 102/102, 97 s and 94 s; the first verdict after the copy arrives at 74.2 s. The same file in a clean `git worktree` of `4acbb783` with `node_modules` linked: exit 0, 102/102, 10 s. In full runs the file took 91–203 s at six lanes and was taken down at 300 s at eight lanes, at load average 11–39.

Next step: copy the tracked tree (with the working-tree content of tracked files, as now) instead of everything but three names, so the fixture does not depend on what else lives in the checkout.

## Work to do

- Build the copy from the tracked file list and keep the current exclusions of generated `lib/`/`bin/` output.

## Out of scope

- Removing the worktrees from the clone: they belong to their sessions and their owner.

## Verification

- The file in a clone with a large ignored tree takes about as long as in a clean worktree, 102/102.
- A probe that plants an ignored file in the checkout shows it is absent from the copy.
