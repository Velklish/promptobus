- **Scope:** [03-cli § Review](../../reference/03-cli.md#review), `lib/spawn.js`, `lib/review.js`, `src/registry.ts`
- **Created:** 2026-09-27

## Context

The declaration accepts an owner named `builder` of kind `edits-tree`, but `spawn` still creates
`worker:<slug>`. PB-274 admits that worker address and uses its result for the owner precondition,
so the gate can proceed while the declared owner name is not the lifted participant's name.
Evidence: `src/pipeline.ts` accepts `{ owner: { name: 'builder', kind: 'edits-tree' }, gates: [] }`;
`lib/spawn.js` constructs `workerAddress(slug)` and prepares the `WORKER` role.
