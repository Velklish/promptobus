## Context

The BB worker skill requires JSON records following the native gate-record and handover-record schemas, with the authenticated bus address in `by`. Both schemas accept only `orchestrator` or a colon-separated address. BB participants use independent participant identifiers: the registered worker address `worker-bs-226` fails both patterns. Replacing it with `worker:bs-226` would invent an identity rather than record the actor that ran the checks.

Source: `schemas/v1/gate-record.schema.json` and `schemas/v1/handover-record.schema.json`, their `by` description and pattern; `bb-plugin-promptobus/skills/promptobus-worker/SKILL.md`, the gate and handover record requirements.
