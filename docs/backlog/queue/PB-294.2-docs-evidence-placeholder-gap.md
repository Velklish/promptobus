# PB-294.2 · Stop treating concrete run captures as placeholders in the documentation task-independence check

- **Order:** 580
- **Scope:** [Reference](../../reference/README.md)
- **Created:** 2026-09-27
- **Dependencies:** none
- **Cost:** major

## Context

PB-294 added `test/docs-task-independence.test.mjs`. The test keeps consumer documentation free of task identifiers, of links into the backlog or the archive, and of references to untracked run artifacts. The third review round of PB-294 left one gap open in the artifact part of that check. The owner accepted PB-294 with this gap filed separately. Today no consumer document contains a reference of the uncaught forms.

Evidence: two exemptions are wider than product layout.

`isPlaceholder` accepts a name as a template on its `gates-`/`handover-` prefix alone. A concrete capture named in prose, such as `gates-review.json` in backticks or a link to `handover-review.json`, is therefore never reported as a missing artifact.

<!-- quote:../../../test/docs-task-independence.test.mjs -->
  if (/^(?:gates|handover)-/.test(base)) return true;
<!-- /quote -->

`isDocumentedProductLocation` passes any JSON path under the product's `.promptobus/` root as a documented location. A concrete capture such as `.promptobus/tasks/run-20260927/files/evidence.json` is therefore not reported.

<!-- quote:../../../test/docs-task-independence.test.mjs -->
  const productRoot = /^(?:~\/\.(?:promptobus|claude|cursor|codex|agents)|\$[A-Za-z0-9_]+|\.(?:claude|cursor|codex|promptobus)|waits)(?:\/|$)/;
  if (productRoot.test(clean) && /\.json$/i.test(clean)) return true;
<!-- /quote -->

The record-naming examples in [04-protocol § Artifacts](../../reference/04-protocol.md#artifacts) must stay legal: `.gates-t2.json` landing as `gates-t2.json`, and `gates-x-2.json` as the numbered repeat of a gate record.

## Work to do

- Limit the placeholder exemption to explicit template forms, and the product-location exemption to documented locations.
- Require a concrete captured file to resolve to a tracked file.
- Keep the 04-protocol naming examples legal through an explicit, narrow exception or through their context.
- Add refusal fixtures for a bare gates/handover capture and for a concrete capture under `.promptobus/tasks/…`. Keep the positive fixtures for real templates and product configuration.

## Out of scope

- Other forms of the documentation task-independence check, and the link verifier's baselines.

## Verification

- Each new refusal fixture fails before the change and passes after it.
- The current consumer documentation stays green.
- A mutation probe that removes the tracked-file requirement turns the new verdict red.
