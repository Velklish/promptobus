# PB-416.1 · Preserve trusted root aliases without admitting symlinks in owned context trees

- **Order:** 450
- **Scope:** [Host](../../reference/02-host.md), [Native context](../../reference/05-drivers.md)
- **Created:** 2026-10-30
- **Dependencies:** PB-415.5
- **Cost:** major

## Context

The pre-migration baseline on macOS uses an aliased OS temp root: os.tmpdir() returns /var/folders while realpath resolves /private/var/folders. Trusted-root spellings and links introduced inside an owned context tree are different cases. The shared service requires one canonical workspace/store identity while retaining its owned-tree protection.

Evidence: `node test/run.mjs --files FILE` failed twice on frozen planning commit 7e0488b706f01211a8399b85f5b386a7cc39ee31 and once on original runtime commit 4503555d9b007bf8b78f4f2bef963b15bb2c2563 for each of codex-holder-implicit-cwd, hooks, install, participant-composition, project-hooks, pipeline, report-channel and report test files. Each passed with canonical TMPDIR on the same source. Source inspection also identifies a parent realpath/text comparison in native-participant-context.js; its effect on a particular aliased context preparation must be reproduced. The matrix establishes a path-spelling sensitivity; it does not establish one common implementation cause for all eight files.

## Work to do

- Reproduce the trusted OS root-alias case with ordinary public preparation and lifecycle APIs. Locate each actual comparison before changing it.
- Canonicalize explicitly trusted root identity once, then retain fail-closed checks against links introduced below that boundary. Cover the shared service's canonical workspace/store identity without weakening reviewer grants, context selection or owned-tree checks.
- Keep distinct defects separate if the eight baseline files have different causes. The TypeScript stages preserve behavior and use a canonical test temp root until this follow-up is accepted.

## Out of scope

- Broad symlink acceptance, user-selected links inside private context trees, changing client authority or treating canonical TMPDIR as a product fix.

## Verification

- Both accepted spellings of one trusted root produce the same bounded result. An in-tree symlink to another location remains refused before writes.
- Repeat the affected files on the original aliased TMPDIR and canonical TMPDIR, recording commands and exit codes. Run the repository gates and independent review; changed tests require committed mutation probes.
