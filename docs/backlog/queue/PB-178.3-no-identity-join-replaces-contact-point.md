# PB-178.3 · A call with no session identity can replace the owner's contact point

- **Order:** 320
- **Scope:** [01-overview § join](../../reference/01-overview.md#join--entering-a-task-hand-over-the-contact-point-and-lift-a-listener)
- **Created:** 2026-09-26
- **Cost:** major
- **Dependencies:** none
- **Parent:** PB-178.2

## Context

Finding discovered while working on PB-178.2. `join()` reads `gated` only. A call with no session is `right: no-identity` and `gated: false`, so it hands over the contact point. `foreignSession` returns immediately for the orchestrator address, so the driver's own check does not stop the write.

<!-- quote:../../../src/mcp/server.ts -->
    const { gated } = service.ownership(home, task, role, session);
    onJoin({ home, task, address: role, gated });
<!-- /quote -->

<!-- quote:../../../lib/server.js -->
  if (!gated) driver.registerWake(home, task, address);
<!-- /quote -->

<!-- quote:../../../lib/store.js -->
  if (!session || addr === ORCHESTRATOR) return null;
<!-- /quote -->

Measured 2026-09-26 in this worktree, exit 0. A task whose owner had already written `wake/orchestrator.json` with socket `/tmp/pb1782-owner.sock` and session `owner-session-aaaa`. An `orchestrator` MCP process with `CLAUDE_CODE_SESSION_ID` empty and `CLAUDE_CODE_MESSAGING_SOCKET=/tmp/pb1782-thief.sock` called `promptobus_task`. The file afterwards was socket `/tmp/pb1782-thief.sock`, session null, pid the child's. The same call with no messaging socket left the owner's file. A foreign session that named itself and carried the thief socket left the owner's file.

## Work to do

- A no-identity call on the orchestrator address must not replace the owner's contact point. `join()` was not changed in the parent: that piece only stops the mailbox fetch.

## Out of scope

- The mailbox peek for `no-identity`, which the parent does.
- A participant address. This gate does not judge it.

## Verification

- After a no-identity call that carries a messaging socket, `wake/orchestrator.json` is still the owner's socket, token and session.
- A foreign session still does not register a contact point.
- The owner still does.
