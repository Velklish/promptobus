## Observed versus expected

Type: operator configuration error; the validator behaved as intended. The private workspace consumer's lead supplied `--permission-mode full-access` for a Codex worker. That value applies to a managed orchestration lead, while the worker role accepts `read-only` or `workspace-write`. The request failed before a worktree, participant, native process, model call or owned slot was created. Expected: select the role's supported profile in the original request.

Full exact installed invocation, role, brief, task, model and stderr are retained at local journal `.promptobus/tasks/tdm-20261109-installed-r4/messages/20261109T231414148-0000-26b49e.json`. Runtime: Host 0.106.2, Promptobus 0.32.7, native binary 0.166.0. This is an attributed producer report, not this record author's own replay.

## Status and workaround

OPEN, record-only operator constraint. The supported worker request later used `workspace-write`; the old refusal remains evidence. Do not change the role validator or claim a failed native launch. The same role-boundary discipline applies to publication: an approver performs local acceptance/fast-forward, and the orchestrator pushes; a consumer brief incorrectly delegating push was corrected before any push (root message `20261110T010343967-0000-5ead95`). No push failure is claimed.
