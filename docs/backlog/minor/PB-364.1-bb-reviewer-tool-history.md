## Context

The constrained provider bridge forwards authenticated tools and receives results,
but emits only agent text and turn boundaries. BB thread history therefore hides
the tool invocation and result that produced a review conclusion. The missing
rows affect observability; canonical send, artifact persistence and mailbox ACK
were verified separately and remain functional.

## Work to do

- Emit correlated tool-open/complete rows for forwarded reviewer tools, with the
  same binding, cancellation and stale-turn protections as text events.
- Keep native tool call results out of duplicate or unrelated turn rows.

## Verification

- A bounded read and an authenticated bus call each produce one correlated BB
  tool row with arguments, completion and result.
- A late result after Stop does not complete a different turn or emit duplicates.

Defer implementation to the owner's minor batch; this finding does not block its parent.
