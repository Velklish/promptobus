## Reproduction and impact

The changed tree was `b5ea0e2e607d2906f7682c20297f632ccb20fa41`; the unchanged baseline was `5f1f08044c8f5f26afd6b65e2e7de272cce0ab3d`. Each command ran twice consecutively on clean HEAD and once on the exact clean base, with restoration to the original branch and clean HEAD after measurement:

- `node test/promptobus-driver-codex.test.mjs`: HEAD exits 1/1, baseline exit 1; 239/240 passed in every run. The same verdict, `: the app-server pattern finds a live stub — otherwise «nothing left» proves nothing`, reports `found []`.
- `node test/promptobus-driver-cursor.test.mjs`: HEAD exits 1/1, baseline exit 1; 160/163 passed in every run. The same three verdicts report no orphan/tool-child processes and a stalled silent turn.
- `pgrep -f '[p]b-350-diagnostic-series.mjs'` for the currently running owned diagnostic series: sandbox exit 3 with `sysmon request failed with error: sysmond service not found` and `pgrep: Cannot get process list`; the explicitly approved read-only invocation outside the sandbox exits 0 and finds that series PID.

Expected: a failed process measurement names its command, exit/status/error and stderr, distinct from a successful measurement finding no matching process. Actual: the Codex helper at test/promptobus-driver-codex.test.mjs:2451–2453 reads only stdout; Cursor helpers at test/promptobus-driver-cursor.test.mjs:1387–1397 and :1405–1406 also discard failure status/stderr. An unreadable process list can therefore become an empty array and a misleading liveness assertion. The isolation change has no branch-only failure-name delta in these repetitions. A complete suite run outside the sandbox is still pending; it is not recorded as passing here, and this card does not claim that every observed suite failure is causally explained.

Full assertions, per-run tree/dirty state, exits/counts, branch restoration and raw output are retained in the private opaque diagnostic artifacts. Machine-specific PID/path values are omitted from this public finding. Current backlog search for process-list permission/probe failures returned exit 1 with no matches before filing.
