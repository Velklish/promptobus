### PQA-4003 - Limit the orphan pickup warning to a repeated review

Audit priority: low. Evidence status: confirmed.

Evidence: skills/orchestrate/SKILL.md:214 and lib/review.ts:1141-1145 say a call without --task will skip the orphan left by a failed review. Directory pickup in lib/review.ts:400-405 has this behavior. The general fallback in lib/store.ts:680-681,698-707 counts all active tasks. lib/done.ts:332 uses it, so a sole orphan can be selected before ownership checks and a second active task can make lookup ambiguous.

Acceptance: Make the failure message and skill limit the pickup guarantee to repeating `review <path>`. Keep the explicit cleanup command `done --task <id>`. Update the diagnostic assertion in test/promptobus-review.test.mjs:2844-2854 and check the wording in the skill. Run npm run test:one -- promptobus-review.test.mjs and node test/documentation-contract.test.mjs.

### PQA-4004 - Explain when solo review uses the recorded branch point
