# PB-315.1 · Qualify historical Codex bus-call cost in launch output

- **Scope:** [Codex driver](../../reference/05-drivers.md), `lib/driver-codex.js`
- **Created:** 2026-10-01
- **Parent:** PB-315
- **Cost:** minor

## Evidence

At published `v0.22.0` (`bb0045455946d26788d7f0d5c89231a63541be44`),
`lib/driver-codex.js:1278` emits:

```text
each bus tool call costs a turn of the Codex auto-reviewer (~3.4 s and ~19 thousand input tokens)
```

A native Codex 0.159.2 managed-root smoke on 2026-10-01 emitted this same
line. That smoke established the launch output, not per-call latency or
reviewer-token cost. Its current cost is unmeasured.

The exported launch reporter reproduces the wording without any native turn:

```sh
node --input-type=module -e 'import { codexDriver } from "./lib/driver-codex.js"; codexDriver.saidLiftoff({ seen: { role: "orchestrator", codexHome: "fixture" } });'
```

Observed on the published tree on 2026-10-01: exit 0; stdout contains the line
quoted above. This command does not measure the cost it prints.

The figures already appear in the [historical driver before its English
translation](https://github.com/Velklish/promptobus/blob/db742f183c14e4ba7556f38dde32e3e071c975e2/lib/driver-codex.js#L402).
That revision declares `PROVEN_CODEX_VERSION = '0.146.0'` at line 45. The
[translation commit](https://github.com/Velklish/promptobus/commit/4eb7093e1e253163ba247db5430bb060fe86d0b0)
is dated 2026-09-04. These are historical provenance, not a new 0.159.2
measurement. The original raw timing/token capture was not verified in this
finding.

`lib/driver-codex.js:58` also states, without a version boundary, that each
bus call costs a built-in auto-reviewer turn. Neither statement qualifies
its old measurement when emitted for the current binary.

## Work to do

Qualify the historical estimate, or remove the unsupported present-tense cost
claim from launch output and participant instructions. Keep measured current
behavior separate from historical observations.

## Acceptance criteria

- Launch output labels retained figures as historical, with their measured
  version and source, or omits the unverified numeric estimate.
- Participant instructions do not assert an unmeasured current extra model turn
  per bus call. A current claim needs a reproducible capture distinguishing
  ordinary tool execution from an additional model turn.
- A regression captures launch output and participant instructions and fails
  when the historical estimate returns as an unqualified current guarantee.
- No current latency or token amount is substituted without its binary version,
  model, date, method and raw capture.

## Boundary

This card files a minor documentation finding. It does not change the driver,
measure current tool-call cost, or revise the published release.
