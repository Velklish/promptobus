## Evidence

Finding discovered while working on PB-343.

Evidence: prepare drops settingsPath/guardCommand: dry-run names files that never land (spawn.js guardHookNote), and no loop-guard hook is installed on the holder

Probe 2026-10-06, opencode v2.0.20 (latest brew): a probe plugin writing a marker at init loads under `opencode run` but never under `opencode serve` — neither from `OPENCODE_CONFIG_DIR/plugins` nor from project `.opencode/plugins`, from the holder cwd or the project cwd; serve logs name no plugin at all. The holder is serve-mode, so no plugin hook (including `session.idle`) can carry the guard there. Return condition: a binary whose serve loads plugins, or a documented holder hook channel.
