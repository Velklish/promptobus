# PB-217 · Result

**Closed 2026-09-16, completed.** Artifact hand-off was silent on three counts, and all three now speak. **(1) A hidden name.** `landedName` strips leading dots when a file lands, collisions are numbered by the landed name rather than by the name the sender typed, and a name made of dots alone is refused before the blob is written; the rule is in [protocol § Artifacts](../../reference/04-protocol.md#artifacts). **(2) A byte-for-byte repeat.** The confirmation names the twin by sha256 — `the same content as <name> (N names)`, the count taken from `nlink − 1` — in the MCP reply and in the CLI, so a reply to the same bytes is no longer indistinguishable from a reply to a corrected file. **(3) A record nobody checked.** A gate record and a handover record are validated at `send` by `lib/schema.js`, a dependency-free reader of the published schema file itself: an invalid record is refused with `<path>: <what>` before the blob is written, and a keyword or a shape the reader does not implement — `$ref`/`oneOf` beside a constraint, `items` as a list, `type` as a list — throws rather than passing half-way, so a schema that grows loses the check loudly. Ten fixtures in the spawn and sweep tests that were `{}` or `{"records":[]}` are now documents the published schema accepts; the subject of those checks is untouched. The worker preamble no longer contradicts itself about what `send` checks: the bus checks the SHAPE and refuses, it does not run these checks or grade them.

**Why a reader of the schema and not ajv.** `ajv` is a devDependency and "the package has no runtime dependencies" is a gate of the suite (`test/promptobus-package.test.mjs`), so ajv at runtime was not available. The pairing `test/v1-validate.test.mjs` already makes for the four engine models is made here too: one fixture set, ajv as the reference, agreement asserted on every document — **35 fixtures for the gate record, 40 for the handover record**, both sets carrying documents of both verdicts.

**What is left open.**

- **`send` reads a record file twice** — once for the schema check and once for the blob write. Bounded by the schema (a gate record caps at 16 entries and a 2000-character tail) and inside the 0.45 ms an artifact send costs, but it is a second read of the same file. Carried into PB-208.1's open list as well, since the second read is on that path.
- **The "how many names" count comes from `nlink`.** On a filesystem without hard links the count is omitted and the twin's name still reported; that branch has no test, because the suite has no portable way to produce such a filesystem.
- **The schema reader is a subset reader.** Its coverage is enforced in two directions — unknown keyword names, and known keywords in shapes it reads only bare — and what protects it is that it refuses to answer outside that subset. Both shipped schemas are asserted to lie inside it.
- **The MCP `sameContent` line changes a reply a consumer reads.** It is the explicit subject of part 2 of this card, so it was made rather than asked; the added text is a suffix and nothing existing moved.
