# PB-206.4 · Result

**Closed 2026-09-13.** The closed list of routed roles lived in three independent projections — `catalog.js` declared `RULE_ROLES`, `resolver.js` declared `ROLES` as its own literal, `telemetry.js` repeated the same triple inside a predicate — plus two hand-written maps in `DEFAULT_POLICY` and four JSON schemas carrying the contract as enums. Adding the fourth role in PB-206 meant editing each of them by hand, and nothing guarded their agreement. Now `ROUTED_ROLES` is the frozen canonical object, both default maps are generated from it, `RULE_ROLES` and `ROLES` survive only as **aliases of the same object** — asserted with `===`, not `deepEqual`, because `deepEqual` would pass exactly the defect this card removes — and the schemas stay static under an explicit parity test.

**What review added, and it was the larger half.** The first pass closed the visible copies; an isolated reviewer then found that the canonical seam had not reached the dictionaries **derived** from it, and both findings were the same shape as the card itself:

- Role-specific warning codes are built as `${role}-floor-not-met`, while `DECISION_WARNINGS` and the schema enum stayed a separate list for three roles. A fourth role would have produced a warning **invalid against the decision schema**, and the parity check could not see that disagreement. Codes are now derived from `ROUTED_ROLES` and checked against `decision.schema.json`.
- `roleMap` created a key for every routed role even when `DEFAULT_ROLE_FLOORS` held no value for it, so the newly added key check passed with `undefined`; the JSON clone in `mergeRouting` then dropped that key and the role routed **without the quality floor it was promised**. A missing, non-integer or out-of-range floor is now refused before `DEFAULT_POLICY` is built.
- A third, smaller one: the telemetry predicate read the canonical list, but no fixture participant held a role outside the old triple, so reverting `lifted()` to the old literal would have left the suite green. The fixture now carries a model-bearing unrouted participant.
