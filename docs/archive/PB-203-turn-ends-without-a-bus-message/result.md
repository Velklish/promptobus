**Closed 2026-09-12.** Done. A turn that ends with nothing sent is now a state of its own, `UNANSWERED`: `lib/answers.js` holds one answer-expectation table and one predicate, `guardVerdict` gained a second branch that returns the turn, and `status` prints the state beside `SILENT` — the line states the debt and claims nothing about the session, because the turn-end mark proves only that a turn ended, not that the session still exists; liveness is read from the session part of the same joined line, and the remedy lives in the reference.
