# PB-204.2 · Результат

**Закрыта 2026-09-13.** Выполнена. Порядок сдачи артефакта сторожится машинно-видимой связью сообщения-артефакта с его результатом: заявкой считается имя приземлившегося файла, названное в строке `Gate` или `Decide`, и результат отвергается, если такого артефакта не присылал никто. Связь `message.artifact` выставляется только для файла, присланного самим отправителем. Схема сообщений v1 не размораживалась — связь легла в существующее поле.

Второй вид нарушения — артефакт послан, ход кончился, результата нет — закрыт сторожем конца хода, а не правилом на ожидании ответа: любая отправка гасит `answerOwedSince`, и правило такого вида не увидело бы.

**Границы, которые пришлось защищать трижды.** Карточка требовала судить только результаты, заявляющие артефакт, и три круга подряд правка оказывалась шире дефекта. Сначала заявкой считался любой токен с точкой — «принять правку lib/store.js» и цитата собственной гейт-команды отвергались, а прозаические лазейки были заданы литералами. Затем совпадение искалось голым `includes`, и приземлившийся `notes.md` ловился внутри `release-notes.md`. Наконец правило «тот же отправитель» запрещало цитировать чужой приземлившийся файл — а это единственный способ ревьюера дать вердикт по записи гейтов автора, то есть сломался бы первый же отчёт после слияния. Цитата и заявка разведены: отказ остаётся на имя, которого не присылал никто.

Граница совпадения проверяет символ до и после: путь `files/gates-artifact.json` по-прежнему совпадает с приземлившимся `gates-artifact.json`, `notes.md` внутри `release-notes.md` — нет, а точка в конце предложения имя не обрывает.

**Проверки.** Гейты 4/4 зелёные на `d8458f8`, дерево чистое, запись `gates-artifact-pb2042-r6.json` проходит `schemas/v1/gate-record.schema.json`. Мутационная проба подменяет предикат `!allMessages.some(...)` на `false`, оставляя чтение каталога нетронутым: мутированный прогон — код 1, красный один названный тест «a landed name with no artifact message from any sender is refused», восстановление — 148/148, код 0. Регрессии стоят на обоих видах нарушения, на отрицательном контроле (обычный безартефактный результат остаётся законным) и на цитировании чужого файла.

Ревью — семь кругов изолированной сессией, стратегия `quality`: 15 находок, затем 7, 5, 2, 3, 2 и чистый проход без единой находки и без переносов.

**Незакрытое.** Обход каталога сообщений по метке `since` был сделан и откачен целиком: он закрывал цену, помеченную ревьюером как рассуждение без замера, и принёс три дефекта — код без тестов, пятую рукописную копию формата и сортировку без потребителя. Цена обхода каталога на конце хода участника не измерена до сих пор; браться за неё следует с замера, а не с правки.

Отказ при отправке теперь срабатывает только на имя, которого не присылал никто, — в штатной работе такая ветка достижима практически лишь при обрыве между записью файла и фиксацией сообщения. Гарантия порядка держится сторожем конца хода и тем, выставлена ли связь; это распределение заложено постановкой, а не получилось после ослабления.
