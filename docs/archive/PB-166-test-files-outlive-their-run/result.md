**Closed 2026-09-12.** Done — but the card's own first bullet closed on a **negative measurement**, and the orphan source in evidence turned out to be a different one.

**The first bullet has no subject in today's tree.** Every one of the 55 suite files was run by hand — `node test/<file>.test.mjs`, the exact form the mutation-probe rule prescribes and the exact form the card says has no deadline — in a pool of three with a 120 s cap: `files=55 lingered=0 failed=0`. Nothing holds a loop open; there was nothing to close. Two of the four orphans the card was written from no longer exist in either repository. That is stated as a measurement, not as a claim that the defect never existed — five live processes were seen when the card was filed.

**The source in evidence was a hand-built measurement stand, not a suite file.** Six live `node -e setInterval(…)` at `PPID 1`, aged 4½ hours, `lsof cwd` pointing at a PB-161 stand from the previous run of this same effort. The evidence was taken — `lsof`, `ps` — **before** anything was killed, which is what the card asked of its next reader and what its own author had failed to do.

**The runner had a real hole, and it was reproduced.** `child.kill('SIGKILL')` reaches the file's process and nothing below it: the file was not spawned `detached`, so there was no group to signal, and a file that had spawned children left them at `PPID 1` — the exact shape of two pairs in the card's table. Before and after, one probe: `64846  1  PB166MARK64840` → no surviving grandchild. Closed by spawning files `detached` and taking them down by negative pid, with `child.kill` behind it as the fallback. The mark carried the probe's own pid in argv and was never matched by program name.

**The single-file run got a watchdog**, an unref'd timer in the helper all 55 files import: a file that empties its loop exits and the timer never fires, and a file still alive at the deadline has by definition something holding it, which `getActiveResourcesInfo()` then names.

**Its cost was found by review and is now stated rather than hidden.** `unref` saves the file that FINISHED and only that one. A file still honestly working at the deadline is taken down like any other — so a second ceiling on a file's whole work was introduced and first described as free. Split by form rather than averaged: under `npm test` the ceiling moves 300 s → 240 s and a file in that band was already failing as "hung", so what changes is 60 s of headroom and a diagnosis instead of a blind kill; **run by hand there was no ceiling at all and now there is one** — a new constraint on the form that previously had none, and the honest price of closing the hole. The header's own record of a 186.5 s file at load average 8 — 0.78 of the new ceiling — is cited in the comment with its provenance. **The watchdog does not catch a spinner**, by construction: a spinner never returns to its event loop, which is also why SIGTERM did not touch the one in the card.

**Two probes came back green and both were verdicts about the checks, not the code.** The negative control did not import the helper, so it could not see the mutation it existed for — «a negative control sitting on a different mechanism from the thing it controls for is decoration». And the take-down check passed with no child in existence: if the child dies on its own it is absent from `ps` too. Both closed, both now bite; the diagnosis is written beside each line so the next reader sees why it is there rather than deleting it as redundant.
