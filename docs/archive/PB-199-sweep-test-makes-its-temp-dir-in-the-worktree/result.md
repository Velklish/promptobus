# PB-199 · Result

**Closed 2026-09-16, completed.** The sweep suite no longer builds a fixture in the checked-out tree, and it now refuses the shape that let it happen. `OWNER_FIXTURE` is `mkdtempSync(path.join(os.tmpdir(), 'promptobus-sweep-owner-'))` — the same absolute form the file asserts of production code four lines above the fixtures it was breaking. The card's second site, `SOCKET_FIXTURE` at `:237`, is not touched here because it no longer exists: it became `makeSockDir('a2s-')` under PB-206.3, which puts the directory under the system temp directory, and `git log -S SOCKET_FIXTURE -- test/tmpdir-sweep.test.mjs` names the commit that did it. After that, one bare `mkdtempSync` was left in the file, and it is the one fixed here.

**The rule is now enforced rather than merely followed.** The walk that already greps `test/` and `scripts/` in both directions for sandbox and temp prefixes gained a third pass: every `mkdtemp`/`mkdtempSync` whose first argument is a string literal is collected, and a literal that does not begin with `/` is reported by name and file. A bare prefix is not a temp path — Node resolves it against `process.cwd()`, the directory lands in the tree under test, and a bus participant, whose shell cannot write its own worktree, gets `EPERM` and no verdicts at all from that file. That is the consequence the card was filed on, and the check exists because being absent today is not being impossible.

**The sentinel is built in three parts, and each part is a place it went blind.** The extraction pattern is lifted out of the loop into `BARE_MKDTEMP` with `literalMkdtemps(text)` beside it, because the walk's own floor comes from the two neighbouring greps: a drift in this pattern alone would leave the verdict green having examined nothing. The rule that decides an extracted literal IS a defect is lifted out beside it as `isBare`, for the same reason — left inline in the loop, no sample can reach it. The samples are then assembled from fragments, because this file is itself inside the walk, and both parts are put under a positive control: a relative literal is caught, `'/tmp/pb-x-'` and `path.join(os.tmpdir(), …)` are not. The verdict itself has no floor of its own, deliberately: zero bare prefixes is the lawful answer today, and what proves the detector can fire is the control beside it, not a count.
