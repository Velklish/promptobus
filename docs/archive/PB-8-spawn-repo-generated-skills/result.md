# PB-8 · Result

**Closed 2026-09-05.** Completed per the owner's decision: a repository declares its generator as `"generate"` (an argv array; a shell string or a malformed value is refused by name and reported, never read as "no generator") in its own `promptobus.json`, read from the clone at plan time and from the worktree at run time. `spawn` runs it after the participant is in the journal (so a Ctrl+C during a long generator leaves no orphan directory) and before the harness launch files and `npm ci`; the launch is rebuilt exactly once with the real outcome, and the participant preamble names it in every case — laid out, exited with a code, not declared, or not re-run on a surviving worktree (without claiming what is still there). A failed generator does not refuse the lift; the operator gets the exit code and a log beside the directory; untracked files a generator leaves are reported, since `done` never sweeps a dirty worktree. `HostFile` in `src/standalone.ts` does not yet declare the field (listed under PB-20).
