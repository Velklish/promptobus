# Roadmap

Where promptobus is going: goals and their rationale. This is a living document: a goal is direction, not a commitment; user signals determine priority and scope, not this list. Concrete tasks with statuses are in `npx github:Velklish/backslop#v0.4.0 status` and [backlog/](backlog/README.md).

## Goals

1. **Host-neutral bus.** A third party runs the CLI and embeds the library without another product's layout. The host contract in [adr-002-standalone-host-contract.md](adr/adr-002-standalone-host-contract.md) is the boundary. Evidence: `src/host.ts`, `src/standalone.ts`.
2. **Three harnesses in one CLI.** Claude Code, Cursor, and Codex share the same task store and the same MCP tools. Evidence: `lib/drivers.js`.
3. **Project-level hook installer.** A person opts in with `promptobus install --harnesses …`. npm `postinstall` does not edit harness files. Evidence: `promptobus help` lists `install` and `uninstall`; their flags are in [guides/install.md](guides/install.md).
4. **Routed model choice instead of a blind flag.** A person or an agent names an intent — a strategy — and the CLI picks the `role + harness + model + effort` tuple from a rated catalog intersected with what the local account can run right now, explains the pick, and never silently replaces an explicit `--harness`, `--model` or `--effort`. Evidence: the decision is [adr-003-model-routing.md](adr/adr-003-model-routing.md) and it is shipped whole — `models/catalog.json` (45 rated tuples), the four contracts in `schemas/model-routing/`, the libraries in `lib/model-routing/` (catalog and overlay merge, validate, preflight, cache, resolver, render, one availability adapter per harness), the host side `routingPaths()` in `src/host.ts`, and the pick of a routed lift in the participant's `metadata.routing`, printed per participant by `promptobus status`. Measured on 2026-09-05 with all three accounts logged in: one `promptobus models --refresh` probed the three harnesses in 2.6 s and chose `codex-luna-medium` at 73.10, naming every one of the 19 candidates with its score components or its exclusion reason.
5. **English runtime output.** New strings are English, and the Russian literals inherited from the transferred code are gone from what runs and from what ships. Evidence: `grep -rlP '[\x{0400}-\x{04FF}]' bin/ lib/ src/ schemas/ templates/` reports only `src/protocol.ts`'s Cyrillic-to-Latin transliteration table and `templates/bus-hook.mjs`'s address-prefix regex (it accepts `воркер`/`ревьюер` alongside `worker`/`reviewer` so a person typing in either language still gets the prefix stripped) — both functional data, not output text.
6. **Three subscriptions spent evenly, not one spent first.** The person pays for three harnesses and the work should use up all three over their own windows instead of going to the best-rated tuple until one account is out. A spike on 2026-09-06 showed every harness can answer what it can run and how much of its window is gone, from local credentials and with no paid turn. The decision is [adr-004-subscription-balance.md](adr/adr-004-subscription-balance.md), and it is shipped whole. Evidence: the availability snapshot is at `schemaVersion` 2 with the tier and every window's `kind`, `lengthSec` and `scope` (`schemas/model-routing/snapshot.schema.json`); each of the three harnesses answers its own tier and windows from local credentials (`lib/model-routing/adapter-claude.js`, `adapter-cursor.js`, `adapter-codex.js`), so `available` — auth, model **and** limit confirmed — is reachable on all three for the first time; `balance` is the fifth value of `STRATEGIES` in `lib/model-routing/catalog.js`, picking by `paceOf` in `lib/model-routing/resolver.js` and printing its pace table through `lib/model-routing/render.js`; quality floors are `qualityFloor: { worker: 3, reviewer: 5 }` and overlay `deny` lists are unioned across layers with the `byRole` and `flags` selectors beside them; `writable?: boolean` on `HostRoutingOverlay` in `src/host.ts` names the one layer `promptobus models strategy --set` writes; and `promptobus done` records what a run actually spent through `lib/model-routing/telemetry.js` against `schemas/model-routing/telemetry.schema.json`. Measured against the suite's own snapshot fixture with the shipped catalog on 2026-09-06: `models --strategy balance --role worker` chose `codex-sol-medium` at 78.10 over `claude-opus-medium` at 74.25 on pace alone — codex `+15.25` effective against claude `+9.23` and cursor `−15.33` — and, with codex staged as exhausted, the same command moved the pick to `claude-opus-medium` and the pace table to two rows.

## Prioritisation principle

A live break or a missing command that a published guide already names comes first. Owner requests next. The backlog order field is the queue, not this list.
