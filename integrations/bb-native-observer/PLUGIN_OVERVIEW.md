Follow native Promptobus tasks beside your BB threads. Discover and select tasks, read canonical questions, status, results, reviews and artifact references, and inspect managed participant identities. Raw JSON remains under Diagnostics.

Configure an enrolled host, an owned task store and a native state directory in Settings. Select a task on the page; the explicit selection persists across page remounts and plugin reloads. The page displays its host, store and task identity. Disconnect pauses observation; reconnect reads fresh data while native work continues independently.

This plugin requires BB 0.49.0, Plugin SDK 0.6.132 and Node 26 or newer. Optional owner notifications wake the explicitly bound BB owner for new questions, results and reviews. They work while the panel is closed, preserve unread mail and do not grant permissions. The plugin does not ACK, launch, recover or stop actors. Recorded activity does not establish process liveness. Full native transcripts, private prompts and command output are unavailable. A result or review does not establish owner acceptance.

The dashboard and owner-notification service ship together. Source checks do not establish live visual acceptance.
